# Module 3 — Demand Forecasting and Prediction

## 1. Overview

Module 3 implements demand forecasting for the Multi-Cloud Smart Supply Chain Control Tower using historical sales data from the M5 Forecasting dataset.

The objective is to predict SKU-level and store-level demand, evaluate forecasting models, and provide demand predictions for downstream inventory optimization.

## 2. Dataset

The module uses the canonical data generated by Module 1.

**Expanded sample configuration:**
- 60 SKUs
- 10 stores
- 3 product categories: FOODS, HOBBIES, HOUSEHOLD
- 600 SKU-store combinations
- 1,941 historical dates
- 1,164,600 records

The expanded sample includes 20 SKUs from each category.

## 3. Data preprocessing and feature engineering

The forecasting pipeline uses:
- Historical sales quantities
- Lag features: 7, 14 and 28 days
- Rolling mean: 7 and 28 days
- Rolling standard deviation: 28 days
- Calendar features: weekday, month and year
- Weekend indicators
- Event indicators
- SNAP indicators

Rolling features use historical observations only, preventing future-data leakage.

## 4. Forecasting models

The module implements and evaluates:

1. XGBoost
2. Moving Average
3. Seasonal Naive
4. Croston
5. Syntetos-Boylan Approximation (SBA)
6. Teunter-Syntetos-Babai (TSB)

The expanded benchmark compares XGBoost, Moving Average and Seasonal Naive across all three product categories.

## 5. Expanded benchmark results

Chronological evaluation:
- Training period: 2011-02-26 to 2016-03-27
- Validation period: 2016-03-28 to 2016-04-24
- Test period: 2016-04-25 to 2016-05-22

| Model | MAE | RMSE | WAPE |
|---|---:|---:|---:|
| XGBoost | 1.2339 | 2.4377 | 76.91% |
| Moving Average | 1.2875 | 2.5702 | 80.25% |
| Seasonal Naive | 1.5667 | 3.3744 | 97.66% |

XGBoost achieved the best performance across all three reported metrics in the expanded benchmark.

### Category-level XGBoost WAPE

- FOODS: 64.94%
- HOBBIES: 90.30%
- HOUSEHOLD: 86.24%

The high WAPE values reflect the sparse and intermittent nature of the sales data.

## 6. Intermittent demand analysis

Croston, SBA and TSB are implemented to evaluate intermittent demand patterns.

The original smaller-sample comparison found TSB achieved the lowest aggregate WAPE among six models. This result is exploratory and should not be directly compared with the expanded three-model benchmark because the evaluation configurations differ.

Demand pattern classification includes:
- Smooth
- Intermittent
- Erratic
- Lumpy

## 9. Limitations

1. The M5 dataset contains historical sales rather than actual on-hand inventory.
2. Zero sales do not confirm stockouts because product availability data is unavailable.
3. Inventory and replenishment decisions require additional inventory and lead-time assumptions.
4. The expanded six-model comparison was not completed; the expanded benchmark reports three models.
5. Historical test predictions are not future operational forecasts.

## 10. Integration with Module 4

Module 3 provides the demand prediction foundation for Module 4 — Inventory Optimization and Replenishment Planning.

Module 4 will use demand forecasts to estimate safety stock, reorder points, inventory risk, and replenishment quantities. Actual inventory data is not available in the M5 dataset, so simulated inventory assumptions must be clearly identified.

## 11. Project integration

- Module 1: Canonical Data Pipeline

- Module 4: Inventory Optimization and Replenishment Planning

The forecasting outputs can subsequently support the Multi-Cloud Smart Supply Chain Control Tower dashboard and alerting workflows.
